# FUTURE_CS_02 - Phishing Email Detection & Awareness System

## Objective

Analyze phishing emails, identify warning signs, classify risk, and create user awareness guidelines.

## Analysis Covered

- Sender analysis
- Suspicious links
- Social engineering indicators
- Risk classification
- Prevention recommendations

## Tools Used

- Email header analysis tools
- Browser inspection tools
- Documentation tools

## Deliverable

- Phishing Detection & Awareness Report
